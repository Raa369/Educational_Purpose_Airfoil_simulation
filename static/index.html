Yang bisa kamu lakukan

Bentuk airfoil sendiri
Atur camber, posisi camber, dan tebal untuk airfoil NACA 4-digit, atau import file .dat untuk airfoil lain seperti Clark-Y atau Eppler.
Simulasi aliran 2D
Solver Navier-Stokes laminar berjalan di server Python, dan aliran dianimasikan langkah demi langkah.
Baca hasilnya
Pilih tampilan kecepatan atau vortisitas, lalu lihat Cl, Cd, dan riwayat gayanya.
Simpan hasilnya
Unduh koordinat airfoil (.dat), riwayat gaya (.csv), dan gambar aliran (.png).

Cara pakai

  1. Pilih airfoil. Geser slider NACA atau ketik angkanya, atau import file .dat.
  2. Atur kondisi aliran. Isi sudut serang dan bilangan Reynolds.
  3. Jalankan simulasi. Tunggu sekitar 10 sampai 60 detik, lalu putar animasinya dan unduh hasilnya.

Yang perlu diketahui

Ini alat untuk belajar dan melihat pola aliran, bukan untuk desain nyata.

Alirannya laminar tanpa model turbulensi, dengan Reynolds 200 sampai 3000. Gridnya kasar, sehingga Cl cenderung terlalu rendah. Pakai hasilnya untuk membandingkan tren antar-parameter, bukan sebagai angka absolut.
